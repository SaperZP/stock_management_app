# Stock Management App

A responsive frontend stock management dashboard designed to simulate inventory and sales workflows in a business setting. Users can interact with sections for products, brands, categories, purchases, sales, and firms through a clean UI and state management powered by Redux Toolkit.

## Features

- User login and registration flow
- Dashboard and sidebar navigation
- CRUD interfaces for:
    - Products
    - Brands
    - Categories
    - Purchases
    - Sales
    - Firms
- Global state management using Redux Toolkit
- Form validation with Formik and Yup
- Responsive and mobile-friendly layout

> 🚧 The backend is currently under update and will be published shortly to enable full functionality.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Axios, Redux Toolkit, Formik, Yup
- **Tooling:** Vite, ESLint, Prettier

## Getting Started

```bash
git clone https://github.com/SaperZP/stock_management_app
cd client
npm install
npm run dev
```
